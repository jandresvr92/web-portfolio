# AGENTS.md

Isometric portfolio built with TanStack Start (React 19, **plain JavaScript, no TypeScript**), Tailwind CSS 3 and Framer Motion. It deploys to Vercel through Nitro. See `README.md` for setup and the folder map.

## Conventions

- Write JS/JSX only. `src/routeTree.gen.ts` is generated by the router plugin on every dev/build run; never edit or commit it.
- Import with the `@/` alias (`@/lib/utils` → `src/lib/utils`). It is defined in both `vite.config.js` and `jsconfig.json`; keep them in sync.
- Pages are server-rendered, so the server and the first client render must match. Read `window`, `document` and storage only in effects or handlers.
- Visible copy comes in three languages (`en`, `es`, `de`). Shared strings live in `src/lib/i18n/dictionaries.js`. Each node keeps its structure (ids, links, dates, images) once in `*Data.js` and its text per language in `*Copy.js`, keyed by the same ids. When you add a string, add it in all three; `npm test` fails if a language is missing one.
- Each `*Data.js` explains how to add an entry, and the layout limits (6 hobbies, 4 blades per stack tab, text lengths) are enforced by `tests/content.test.js`. Counts and years are computed from the data: never write them into the copy.
- Static files go in `public/images/` or `public/cv/`, never `public/assets/`: that path is reserved for Vite's hashed bundles and cached immutably on Vercel. The only exceptions are the site icons (`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`), `robots.txt` and `sitemap.xml`, which stay at the root of `public/` because browsers and crawlers request them there. `robots.txt` and `sitemap.xml` repeat `SITE_URL` from `src/lib/site.js`; the tests check they match.
- `vite.config.js` plugin order is `tanstackStart()`, `nitro()`, `react()`, as in the TanStack Start hosting guide.
- `nitro` is pinned to an exact release candidate (v3 has no stable release yet). Upgrade it on purpose, and check `npm run build` and `NITRO_PRESET=vercel npm run build` afterwards.

## Before finishing a change

```bash
npm run check   # lint + content tests + build
```

Then open the site with `npm run dev` and click through the nodes on desktop and at mobile width.
